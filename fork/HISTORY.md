## 3.6.1Q2（2026-10-30）

### 修复

- **多窗口下打开两次「设置 → 选项」会让程序崩溃**（Q1 已知问题第 1 条）：选项页的状态现在跟着
  窗口走而不是共用一个全局，且同一时刻只允许一个选项页——第二次打开会把已有那个带到前台。
- **同名替换的 `.caj` 仍显示旧内容**（Q1 已知问题第 2 条）：源文件的体积或时间变了会真的重新
  转换。旧代码只写了一条"要重转"的日志，却因为旧产物还在而跳过，还先把新体积/时间记进了清单，
  于是那条缓存自洽地永久错误。
- **转换中途被强杀或磁盘写满留下的半个缓存文件**（Q1 已知问题第 3 条）：转换先写到同名加 `.tmp`
  的临时文件再原子改名替换，最终名上不会再出现半截文件；命中缓存前还要验一下文件头是不是
  `%PDF-`，被写坏的旧残留会自动重转而不是一直打不开。
- 转换失败时不再留下指向已释放内存的缓存条目（下次打开别的 CAJ 会读到它）。
- **多标签时标签条比标题栏右侧按钮低 11 px、头顶一大片空隙**（就是你反馈的那条）：标签条的位置与高度改成问系统
  （DWM 报的标题栏按钮带），并把它在带子里从「贴底」改为「垂直居中」。实测：窗口态与最大化态下，标签中心与按钮中心
  都从差 11 px 变成 **差 0 px**，带内余量从「上 6 / 下 0」变成「上 3 / 下 3」。只在 100% 缩放下量过，其它缩放的观感请你看。
- **顶部边框拖动缩放被我改坏又补回**（同一轮里那次对齐把缩放手柄吃掉了）：标题栏带子顶部 8px 现在仍是缩放手柄，
  标签条顶部这 8px 会把点击让给边框；点标签或拖标签请落在下面那 16px 内。实测顶边 2/4/6px 处均为 HTTOP(12)，
  12px 处恢复可点击（HTCLIENT），标签与按钮的垂直中心差仍是 0。
- **最大化时标题栏被截断也修了**（同一个对齐改动的另一面）：最大化窗口矩形向屏幕外扩了 8px，
  照抄系统报的标题栏带顶会把标签条顶上 5px 推到屏幕外（所以看着特别矮）。现在最大化时带子从
  可见顶边起算，实测裁切 0px、标签与按钮可见部分中心差 1px；非最大化态仍是中心差 0。
- **选项页的颜色改走主题参数**：选项区背景不再用系统按钮灰，而是与 PDF 外围同一层颜色
  （就是 PDF 页面那一层的 `FixedPageUI BackgroundColor / TextColor`，
  Light 主题下选项区是**白底黑字**、标题栏保持系统灰，按钮与「更改语言」窗口同一套普通按钮）。
  文字颜色走 `ThemeWindowTextColor()`。Dark 主题下差别最大：原来是灰底黑字，现在黑底白字。
  有门禁盯着「改参数读数必须跟着变」与「底字必须有对比」：Light `#ffffff`+`#000000`、
  自定义 `#ff00aa`+`#ffffff`、Dark 主题下仍是白底（应用的暗色主题不改页面色）。
- 缓存清单 `index.txt` 按不可信输入处理：含路径分隔符、`..`、制表符或超长的行一律忽略，
  因此手改过的清单不能再让程序删除或打开缓存目录之外的文件。
  **新增问题**：修其中一条时我自己引入了一个中文文件名截断缺陷（汉字被截成半个字节序列，
  中文 `.caj` 从此打不开），已由回归测试逮住并修好——记在这里是因为它是我改出来的，不是上游的。

### 变更

- 若某个旧缓存 PDF 仍被打开的标签页占用，替换会失败并明确报错（提示先关掉那个文档），
  不再静默给你看旧内容。

## 3.6.1Q1（2026-10-30）

### 新增

- **直接打开 CAJ（知网私有电子论文格式）**：转换库 caj2pdf-core 编进 exe 内部，
  双击即出画面，不需要外挂转换器、不需要先另存。转换产物交给同一个 PDF 引擎，
  所以书签目录、全文搜索、缩略图侧栏、批注、打印与 PDF 完全一致；也可以「另存为」导出 PDF。
- **CAJ 缓存**：产物存在 exe 旁边的 `caj-cache/`，文件名＝原文件名换后缀（`论文.caj` → `论文.pdf`），
  同一份文件用不同方式打开（双击 / 命令行 / 拖放 / 8.3 短名）只留一份缓存；
  同名不同来源的文件用 `__2`、`__3` 区分并可分辨地共存；`index.txt` 记录映射与最近使用时间，
  30 天未再读取的自动回收；索引文件损坏或被手改坏时仍能正常打开。
  64 页样本实测：首次转换 293 ms，命中缓存后 5 ms 级。
- **选项设置页（设置 → 选项）**：9 个「菜单、工具栏、鼠标操作里都改不到、只能手改配置文件」的开关，
  单页单栏，需要重启才生效的项在标签上直接标「（需重启）」。入选判据是硬的：
  能在别处改的一律不放（如界面主题在「设置 → 主题」里就有，因此不在这里）。
  列出的项：文档以标签页打开、启动时恢复上次文件、记住打开过的文件、新文件交给已运行实例、
  标题栏显示完整路径、平滑滚动、每个文档记住阅读状态、文件改动时自动重载、大文档延迟加载。
- **自有版本号**：3.6.1Q1，显示在「帮助 → 关于」的版本串与 exe 属性页的「文件版本」里
  （数值型 FILEVERSION 保持 3.6.1.0，让按数字比版本的系统仍视其为 3.6.1 家族）。
- **「帮助 → 关于」页署名**：新增 Author = 邱宗满，以及 Gitee / GitHub 两个可点击的仓库链接；
  上游原有的五行（website / manual / forums / programming / licenses）文本与链接全部保留。
- **本 README 与本 HISTORY**：仓库首页从此讲的是改版，而不是官方版介绍。

### 变更

- **对外可见的名字改为 `SumatraPDF-Q`**：exe 文件名、窗口标题、任务管理器里的进程名
  （PE 的 `FileDescription`）。内部一律保持原名——注册表键、卸载串、AppData 目录、窗口类、
  `ProductName`、上游版权声明都不动。
- **禁止官方更新检查**：官方更新包会把本改版整个覆盖掉，CAJ 与选项页功能无声丢失。
  自动检查的开关默认关闭；手动「检查更新」（菜单与命令面板里都有）也一并拦下并给出提示，
  指回本仓库下载页。起始页的官方推广串本就走更新检查响应，随之关闭。
- **崩溃报告不再上传官方服务器**（也不再从那里下载符号）：本改版的 bug 不该记到官方账上；
  崩溃转储仍写在本地。
- **便携首启默认值**：不再自动恢复上次打开的文件（`RestoreSession = false`）、
  不再默认检查更新（`CheckForUpdates = false`）。这是官方设置项的两个默认值，
  没新增任何配置项。

### 已知问题

- **多窗口下开两次选项页会导致程序崩溃**：`Ctrl+N` 新建窗口 → 在窗口 1 打开「设置 → 选项」→
  再在窗口 2 也打开一次，之后点第一个页面的按钮会崩。请避免这个操作路径（修复已在计划中）。
- **同名替换的 `.caj` 可能仍显示旧内容**：同一位置放了内容不同的同名文件时，会命中旧缓存。
  临时办法：删掉 `caj-cache/` 里那个同名 `.pdf` 再打开。
- **转换过程被强杀或磁盘写满**，可能留下半个缓存文件并被后续打开一直命中，
  该文件从此打不开。临时办法同样是删掉 `caj-cache/` 里的同名 `.pdf`。
- 以上三条与其他审计发现（缓存清单可被路径穿越、跨进程无锁、构建配置未纳入 premake）
  的完整记录见 `CHANGES.md`（开发侧另有不入库的笔记）。
